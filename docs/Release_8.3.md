# FrameGrab 8.3

- Built-in public GitHub Releases updater; no user-entered URL required.
- Seven complete color themes, theme previews, durable appearance preferences and reduced-motion support.
- Native Browse button before downloading, per-download destinations, default folder persistence, writability/space checks, and correct output history.
- Refined page/button/notification/progress motion without continuous wallpaper rendering by default.
- Download pause/resume where the source supports partial recovery; cancel, retry, Open File/Folder and Copy Path.
- Preserves Premiere Optimized H.264/AAC/CFR processing, NVENC with CPU fallback, retained-source conversion retry and optional proxies.

NSIS differential downloads are enabled; a full verified download is used when a suitable old installer/blockmap is unavailable. Existing data is retained by the stable application identifier and uninstall settings. No zero-lag or universal tiny-update guarantee is made.
