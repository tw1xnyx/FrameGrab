# FrameGrab 8.3

- Built-in public GitHub Releases updater; no user-entered URL required.
- Seven complete theme families in both Light and Dark, theme previews, durable appearance preferences and reduced-motion support.
- Native Browse button before downloading, per-download destinations, default folder persistence, writability/space checks, and correct output history.
- Refined page/button/notification/progress motion without continuous wallpaper rendering by default.
- Download pause/resume where the source supports partial recovery; cancel, retry, Open File/Folder and Copy Path.
- Preserves Premiere Optimized H.264/AAC/CFR processing, NVENC with CPU fallback, retained-source conversion retry and optional proxies.

NSIS differential downloads are enabled; a full verified download is used when a suitable old installer/blockmap is unavailable. Existing data is retained by the stable application identifier and uninstall settings. No zero-lag or universal tiny-update guarantee is made.

## Theme polish
- Prismatic Studio, Neon Graphite, Aurora Mesh, Rose Quartz OS, Neo Tangerine, Matcha & Cobalt and Holographic Titanium: fourteen exact user-supplied palettes, with palette-specific surface hierarchies, complementary colors, readable gradient actions and distinct material details.
- Correct colors for native Windows chrome, diagnostics, errors, disabled controls, download stages, trim controls, placeholders and scrollbars.
- Correct sidebar selection on every page; larger labels and steadier visual hierarchy.
- Lightweight hover, active-tab, theme, page, notification and real progress transitions; live reduced-motion support.
- Sticky download action while scrolling the existing advanced and clipping controls.

All 196 supplied color values remain unchanged in the central palette contract. Additional foreground roles derive readable shades from those values only when needed for contrast. Existing saved family names migrate without losing appearance preferences.
